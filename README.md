# e-Manager · 企业数字员工管理平台

**让 AI 从单点对话，走向有身份、有权限、有交付的企业数字员工。**

e-Manager 将数字员工、专业技能、业务系统连接和任务交付放在一个管理平台中。员工通过桌面工作台使用能力，管理者集中配置、授权和审核。

## 产品组成

**数字员工管理中心**：集中维护数字员工、Skill、业务系统连接、使用授权与质量反馈。

**个人桌面工作台**：提供员工切换、对话、任务跟进、材料提交和产物获取。

**Group Studio**：围绕业务目标组织多员工协作，让计划、复核与交付过程可以查看和确认。

**共享执行底座**：承接任务与工具调用，连接不同渠道，保留权限和执行边界。

## 企业部署与交付

产品由管理中心和桌面端协同组成。企业部署需要配置身份认证、模型服务、业务系统连接及对应权限；系统适配能力取决于目标系统已开放接口与用户授权。

产品仍在持续迭代。商业交付的功能范围、适配系统、部署环境、配套服务和验收标准以双方书面约定为准。

此目录用于独立公开发布。源码快照与安装包将在完成发布审阅后提供；内部开发历史、私有配置和运行数据不属于公开交付内容。

## 公开发布范围

公开版本包含 Center 平台源码及桌面客户端安装包。数字员工定义与角色素材、Skill 包与内容、业务提示词、企业配置、凭证及运行数据不随公开版本交付。公开版本从空资产目录开始，由使用方通过平台导入并审核自己的数字员工和 Skill。
