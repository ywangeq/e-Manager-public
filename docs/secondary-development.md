# 二次开发与资产扩展

## Center 源码是否提供？

提供。1.0 的计划交付包括 Center 前端、服务端、通用 Runtime、资产导入与治理机制、本地安装和启动脚本，以及 Group Studio 桌面端源码和 macOS arm64 包。

目前公开分支仍是文档审核稿，源码和安装包尚未上传。独立本地候选已完成构建与基础登录验证，正在进行公开出口检查；正式发布后，源码会进入本仓库，安装包会放在 GitHub Releases。此说明不是已经发布 1.0 的公告。

Center 包是 ZIP：解压、安装依赖、初始化账号，再通过命令启动。需要 Node.js 24.13+ 和 pnpm 11；不是双击安装器，也不附带 Node.js。候选版的启动命令如下，正式交付以发布包内说明为准：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm local:install
pnpm start
```

预构建 Center 包带有前端产物；从源码开发还需要在启动前执行 `pnpm build`。本地访问地址为 `http://127.0.0.1:14878`，账号为 `admin@localhost`，每次全新安装生成独立密码并保存到本地 `data/local/first-login.txt`。仓库不提供共用密码、用户数据或密钥。

Group Studio 是 3.x 产品线；“1.0”指本次公开交付版本，不代表采用旧桌面 2.x。桌面包不自动安装或启动 Center，应先启动 Center。当前桌面候选仅验证 macOS arm64 构建与启动，未完成完整登录、资产导入及模型执行验收；Windows、签名与公证尚未验证。

## 用户从哪里开始？

| 目标 | 工作方式 | 必须由使用方提供或验证的内容 |
| --- | --- | --- |
| 本机查看管理界面 | 安装并启动本地 Center，使用独立本地账号 | Node.js、pnpm；本地数据和密钥备份 |
| 使用自己的模型 | 配置现有 Provider 支持的协议、模型和凭证 | 模型服务权限、费用、工具调用兼容性；不支持的协议需开发适配 |
| 添加员工和 Skill | 制作自己的资产包，走导入、评审、发布和挂载流程 | 职责、提示词、输入输出合同、权限范围；包含脚本或专用工具时还需开发测试 |
| 连接业务 API | 使用现有受控 Tool/OpenAPI 能力配置契约与允许操作 | API 地址、目标系统用户授权、测试环境；专有鉴权与数据转换需开发适配 |
| 接入企业登录和组织 | 开发认证与身份映射，再完成权限联调 | 企业 SSO、账号/部门映射、账号停用及权限刷新；本地登录不提供企业权限 |
| 接入飞书或其他渠道 | 配置已有渠道并联调；其他渠道开发适配器 | 自己的应用凭证、订阅与权限，真实消息回环；本地安装不自动获得外网回调能力 |
| 改界面、运行逻辑或部署方式 | 修改公开源码，在自己的分支维护 | 构建、回归验证、迁移和部署运维 |

独立本地版本仅监听本机 loopback，不适合作为局域网或互联网企业服务直接暴露。企业部署需要单独完成认证、网络、HTTPS、存储、密钥管理与运维适配。

## 扩展代码应该放在哪里？

源码发布后，按现有职责定位修改入口：

| 目录 | 用途 |
| --- | --- |
| `src/components/`、`src/lib/` | Center 界面与可复用前端逻辑 |
| `server/auth/` | 身份与会话授权；其他企业认证需要在此边界适配 |
| `server/agent-runtime/` | 共享任务执行平面；新增渠道仍应进入同一 Runtime |
| `desktop-channel-mvp/` | Group Studio 桌面界面、设备能力与本地 Center 连接 |
| `tools/` | 本地初始化、启动、打包与检查脚本 |

业务职责与提示词优先放入独立资产包；外部系统差异由 Tool 或适配器承接。资产导入不自动获得运行权限，也不替代目标系统的 RBAC。这里是现有代码职责说明，尚未承诺稳定插件 SDK、任意热加载或平台升级后自动兼容所有自定义扩展。

建议用户在自己的仓库维护平台修改，在独立目录或资产仓库维护自建资产，记录依赖的平台版本。升级前备份数据与密钥，并验证自定义接口和资产；不要直接覆盖已有运行数据。

## 免费与付费资产怎么区分？

本次公开候选的员工和 Skill 目录为空，现有业务员工、Skill 内容、业务提示词、角色素材、企业配置和运行数据不会随 1.0 上传。演示视频展示的业务能力不等于安装包附带的资产。

后续计划提供少量原创免费 Demo，帮助体验导入、审核和执行流程；成熟业务员工、专业 Skill、工作流模板与工具组合可作为独立付费资产包交付。目前没有已发布的免费示例包或付费资产商店。

付费资产的交付清单和授权应明确：是否提供可修改的内容或源码、可用组织与部署范围、修改与内部复用、再分发、兼容版本、更新和支持。第三方内容继续遵循各自许可；企业私有内容和客户数据不会因为打包而自动获得对外授权。
