# 免费导入示例

`text-summary` 是本仓库原创的文本摘要 Skill，采用仓库 LICENSE。它不包含员工、模型凭证、业务资料或外部 Tool。

发布附件 `e-manager-example-text-summary-1.0.0.zip` 包含 SKILL.md 和身份清单。启动 Center 后，在资产导入入口上传该包，检查解析出的技能名称、输入输出和边界，再按界面完成评审。导入不会自动发布、挂载或运行。Agent 预审和实际执行仍需要用户配置模型；审核和员工配置也需由使用方完成。

已验证 ZIP 安全解析和 Skill 身份读取；未验证完整界面审核、员工挂载和真实模型输出。此示例用于提供制作起点，不预装到默认目录。

修改后请同步包版本；制作独立业务资产时使用自己的稳定 ID，避免覆盖该示例。

Skill 归档导入还需要 PATH 中有 `python3`、`unzip` 和 `tar`；Python Harness 需另行准备对应执行依赖。
